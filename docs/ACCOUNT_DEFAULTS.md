# 固定資産登録の勘定科目デフォルト

マスタ管理の「固定資産登録の勘定科目デフォルト」で、選択中の会社の初期値を保存します。

- 会計簿・税務簿それぞれで、資産勘定科目・償却費勘定科目・累計額勘定科目を指定できます。
- 「会社共通」と「資産分類別」を設定できます。分類別、会社共通、標準設定の順に優先します。
- 標準設定は資産科目が分類の標準科目、償却費科目6100、累計額科目1590です。
- 新規登録、登録フォームでの分類・法定耐用年数選択に反映します。フォーム上で個別変更できます。
- CSVの新規登録で科目指定を省略した場合も適用します。明示した科目を優先します。
- 登録済み資産は変更しません。CSV更新で科目指定を省略した場合も既存科目を保持します。
- システム管理者または対象会社の会社管理者が保存できます。選択中の会社の科目マスタのみ使用できます。
- 確定済期間があっても変更できます。過去の償却実績・仕訳への影響はありません。
- 設定は監査ログ・バックアップに保存し、会社のアーカイブ・復帰時は保持、会社の物理削除時は当該会社分のみ削除します。
