# 一括償却資産（3年均等償却）

新規登録・変更の償却方法で「一括償却資産（3年均等償却）」を選択します。会計簿・税務簿は別々に選択できます。資産分類「一括償却資産」を選んだ場合は、両簿にこの方法を初期設定します。

## 登録条件

- 資産の取得価額と適用する簿別取得価額は、それぞれ20万円未満です。20万円ちょうどは対象外です。消費税は既存の取得価額への自動加算をせず、利用する経理方式の最終計上額で判定します。
- 償却年数は3年、最終残存簿価は0円に自動設定し、入力欄を固定します。
- 土地・建設仮勘定・のれん・未対応のリース分類等には適用できません。
- 貸付用（主たる事業として行うものを除く）や一定のリース資産などの除外条件は、利用者が確認してください。制度上の適用選択・申告書添付等を自動で行う機能ではありません。

## 年額と月次配賦

会社・会計／税務簿・事業供用年度ごとに取得価額を合算します。標準12か月の事業年度を対象とし、供用年度を含む3事業年度で償却します。個人事業主は暦年です。短期決算・決算期変更・償却不足額の繰越調整は未対応です。

初年度は供用月にかかわらず年額を合計取得価額の3分の1として計算します。月次帳簿では、その年額を供用月から決算月までに配賦します。翌年度以降は12か月配賦し、3年度目に残額を調整して帳簿価額を0円にします。通常の「定額法・耐用年数3年」や供用から36か月の償却とは異なります。

例：3月決算で2026年10月に18万円の資産を供用した場合

| 期間 | 年額 | 月次配賦 |
|---|---:|---:|
| 2026年10月〜2027年3月 | 60,000円 | 10,000円×6か月 |
| 2027年4月〜2028年3月 | 60,000円 | 5,000円×12か月 |
| 2028年4月〜2029年3月 | 60,000円 | 5,000円×12か月 |

税務の年額は法人では円未満切捨て、個人では切上げ、会計の年額は会社の会計端数設定を使用します。月次の基礎額は切捨て、残差は決算月に調整します。一括償却の月次端数は通常償却の指定調整月設定にかかわらず決算月で処理します。同じ年度の複数資産についても合算後の年額と明細合計を一致させます。

後月に供用する資産を追加しても、それ以前の確定済み月の金額・残高を変更しません。グループ端数は決算月で調整します。

## 売却・除却

一括償却を選択した簿では、処分後も3年の償却を継続します。残額を処分月の償却費・除却損として一括計上しません。会計簿が通常償却、税務簿が一括償却の場合は、会計簿のみ通常の処分処理を行い、税務償却は継続します。

会計簿も一括償却の場合、売却収入があれば収入分のみの仕訳を生成します。無償除却では除却損仕訳を生成せず、その旨を画面と監査ログに記録します。帳簿残高は処分済み表示になっても一括償却の残高を保持します。

## CSV移行・初期残高

CSVの償却方法コードは `lumpSum3` です。会計簿は `accounting_method`、税務簿は `tax_method` に指定します。年数3・残存0へ正規化してプレビューへ表示します。

移行基準日は処理開始月の前月末かつ決算月末とし、供用年度の決算月末以降を指定します。移行時は同一供用年度の全件を同じCSVに含め、年度合計の初期累計額を経過年数・年額と一致させてください。既存のグループの端数配賦による資産ごとの差は許容し、グループ全体で整合性を検証します。3年経過済みの残高は0円です。減損・改定取得価額は指定できません。

既存の通常償却資産を自動で一括償却へ変更することはありません。確定済み資産を変更する場合は既存の確定保護が適用されます。
