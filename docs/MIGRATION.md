# Excel・他システムからの固定資産移行

Excelの表を移行CSVテンプレートに合わせ、CSVとして保存して取り込みます。Excelファイル（.xlsx）の直接読み込みは行いません。

## 手順

1. 選択会社を確認し、システム管理で全データをバックアップします。
2. 確定済み期間に属する資産を追加・修正する場合は、減価償却画面の「全期間確定・取消」で「全期間確定取消」を選びます。対象期間を確認し、理由・レビュー確認・確認文を入力して実行します。出力済み仕訳があると取消を拒否します。未出力仕訳は同時に取り消します。
3. 会社・会計設定の「月次処理開始月」を移行後に計算を開始する月に合わせます。部門・使用場所・勘定科目も先に登録します。
4. 固定資産の「CSV読込」で「移行CSVテンプレートをダウンロード」を選びます。
5. Excelや旧システムの項目をCSV列に合わせます。テンプレートはUTF-8です。読込時には実ファイルに合わせてUTF-8またはShift-JISを選んでください。1回の取り込みは1000資産までです。
6. 新規・更新・新規と更新の混合のいずれかを選び、登録前プレビューを実行します。資産番号が会社内の照合キーです。
7. 行別検証結果の「詳細」で変更前後、簿別取得価額、償却方法、初期累計額・帳簿価額などを確認します。エラーや重複がある場合は修正します。対象外としてスキップされた行は登録しません。
8. レビュー確認にチェックして「レビュー完了・登録確定」を実行します。CSV内容・処理モード・会社・レビュー時点のデータが変わると再レビューが必要です。取り込みは全行を1トランザクションで保存します。
9. 減価償却画面の「全期間確定・取消」で「指定年月まで全期間一斉確定」を選びます。最終年月と理由を入力し、対象期間・資産をレビューして実行します。

一斉確定は次の未確定月から指定月まで、毎月の計算と確定を自動で順番に実行します。各月ごとの保存なので、途中停止・エラー時には完了済みの月を保持します。「対象期間を確認」を再実行すると続きから再開できます。仕訳は自動生成しません。必要な仕訳を再確定後に会計連携画面で生成してください。

## CSV列

| 列 | 内容 |
|---|---|
| number / name / category | 資産番号・名称・分類の固定識別名。資産分類の表示名称と識別名が異なる場合は識別名を使用 |
| acquisition_date / service_date | 取得日・供用開始日。YYYY-MM-DD または YYYY/MM/DD |
| cost / tax / ancillary | 最終計上取得価額・消費税内訳・付随費用内訳。内訳は取得価額へ自動加算しません |
| accounting_method / tax_method | 簿別の償却方法コード |
| accounting_life / tax_life | 簿別の耐用年数 |
| accounting_residual / tax_residual | 簿別の最終残存簿価 |
| accounting_cost / tax_cost | 簿別取得価額。新規の空欄はcostを使用 |
| department_code / location_code | 選択会社に登録した部門・使用場所コード |
| manager / supplier / manufacturer / model / serial / notes | 責任者・取得先・メーカー・型式・製造番号・備考 |
| accounting_account / tax_account | 簿別資産勘定科目コード |
| accounting_expense_account / tax_expense_account | 簿別償却費勘定科目コード |
| accounting_accumulated_account / tax_accumulated_account | 簿別償却累計額勘定科目コード |
| accounting_opening_as_of / tax_opening_as_of | 初期残高基準日。会社の処理開始月の前月末 |
| accounting_opening_accumulated / tax_opening_accumulated | 初期残高基準日の償却累計額 |
| accounting_opening_revised_basis / tax_opening_revised_basis | 定率法の改定取得価額。切替済み資産の移行時に指定 |
| accounting_legacy_tail_start / tax_legacy_tail_start | 旧制度で95％到達後の5年均等償却を始める年月 |

最初の14列（numberからtax_residualまで）のヘッダーは必須です。追加列は省略可能です。通常の空欄は更新時の既存値を維持します。`__CLEAR__` は値のクリアです。初期残高を解除する場合は該当簿のopening_as_ofに指定します。

一括償却資産の方法コードは `lumpSum3` です。同じ供用年度の全件をまとめて移行し、初期残高は決算月末基準としてください。詳しくは[一括償却資産の仕様](LUMP_SUM.md)を参照してください。

主な方法コードはstraight（定額）、declining200・declining250（定率）、oldStraight・oldDeclining（旧制度）、none（非償却）、goodwill（会計のれん）、immediate（即時費用化）です。適用可能な分類・取得日・年数・残存簿価は通常登録と同じ検証を行います。

## 初期残高の扱い

処理開始月より前から供用している償却資産には初期残高が必要です。帳簿価額は「簿別取得価額 − 初期償却累計額」で算出します。会計簿・税務簿の累計額は別々に指定できます。

定率法の初期残高は決算月末基準のみ対応します。減損後の償却など未対応の条件は検証エラーになります。移行元の計算結果と本システムの結果が一致するか、帳簿残高・端数処理・月次配賦を照合してください。

全期間取消は処理開始月や初期残高を変更しません。元の確定実績は削除せず取消状態として保持し、取消・CSV登録・一斉確定を監査ログへ記録します。
