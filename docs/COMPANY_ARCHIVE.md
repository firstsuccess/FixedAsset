# WORKSPACE（会社）のアーカイブ管理

システム管理者が「システム管理 → WORKSPACE（会社）のアーカイブ管理」から操作します。全会社共通のマスタは、この機能では削除しません。

## ① アーカイブ

「会社をアーカイブ」を選択し、運用中の会社と理由を指定して実行します。

- 会社の資産・償却実績・仕訳・会社別マスタ等はデータベース内に保持します。
- WORKSPACEの会社一覧から非表示になります。
- 通常の業務画面・APIの閲覧、更新、CSV出力、一括確定等を拒否します。
- 使用中の画面で対象会社をアーカイブした場合は、残りの運用中会社へ切り替えます。運用中会社がゼロでもシステム管理のアーカイブ管理は使用できます。

## ② 本番復帰

「アーカイブ会社を本番復帰」を選択し、アーカイブ済み会社と理由を指定して実行します。

WORKSPACEの会社一覧へ再表示され、保持していた資産・実績・設定・会社別権限を再利用できます。

## ③ 物理削除

物理削除はアーカイブ済み会社に限定します。

1. 必要なバックアップを保存します。
2. 「アーカイブ会社を物理削除」で対象会社と理由を指定します。
3. 「物理削除の対象件数を確認」を実行します。
4. 対象会社・件数をレビューし、レビューとバックアップ保存の確認欄にチェックします。
5. 確認文 `DELETE 会社コード` と、操作する管理者の現在のパスワードを入力します。
6. 物理削除を実行します。

会社本体、会社別マスタ、資産・償却簿・初期残高、償却実績、仕訳、会社別権限、関連する会社別履歴等を、子データから順に一つのトランザクションで削除します。会社をまたぐ不整合を検出すると、削除を中止します。途中で失敗した場合は一切削除せず、元の状態へ戻します。

ユーザー本体は保持し、削除会社・部門への所属参照のみ解除します。他社への権限も保持します。物理削除の最小限の操作記録（会社ID・件数・操作者・理由）は会社を参照しないシステム監査ログへ残します。

**保持する全社共通データ：** 資産分類、耐用年数、償却方法、償却率、権限ロール、システム共通設定、ユーザー、共通カウンター等。対象会社専用のアーカイブ状態だけを解除します。

削除対象を確認した後に他の更新があった場合は、再確認が必要です。物理削除した会社は「本番復帰」で戻せません。保存したバックアップファイルは、この機能では削除しません。

## バックアップと復元

全データバックアップはアーカイブ会社とそのアーカイブ状態も含みます。バックアップを全データ復元した場合、保存時点でアーカイブされていた会社は非表示の状態で復元されます。
